#  Air Draw – Virtual Air Drawing Using Hand Gestures

## About the Project
Air Draw is a Python-based project that allows users to draw in the air using hand gestures detected through a webcam.

It uses computer vision and hand tracking to create a virtual drawing experience without touching a screen.

## Technologies Used
- Python 3.11
- OpenCV
- MediaPipe
- NumPy

## Features
- Real-time hand detection
- Webcam-based tracking
- Virtual air drawing
- Touch-free interaction

## Installation

1. Clone this repository.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the project:

   python "Air draw1.py"

## How It Works
The webcam captures hand movements.
MediaPipe detects hand landmarks, while OpenCV processes the video frames.
